# EPD Standup Demo Project

This repository contains sample engineering work for the **EPD Standup Copilot** demo.

## Demo workstreams

- Payment performance: Jira `SCRUM-5` and `SCRUM-6`
- Editor autosave reliability: Jira `SCRUM-7` and `SCRUM-8`

The code is intentionally small so Jira issues, GitHub pull requests, Slack discussions, and Notion standup records can be traced end to end.

## Commands

```bash
npm test
npm run benchmark:payment
```
